═══════════════════════════════════════════════════════════════════════════════

ROOT CAUSE EXPLAINED:
═══════════════════════

Problem: Windows + OneDrive + Async I/O = Timeout

Why?
1. Windows lacks true async file I/O (no io_uring)
2. OneDrive sync interferes with file streaming
3. Async handlers blocked by filesystem operations
4. httpx expects non-blocking writes, gets blocking reads

Solution:
1. Read entire file into BytesIO buffer (sync operation)
2. Upload buffer (no filesystem I/O during upload)
3. Cache file_id immediately
4. All future sends use file_id (no file access)

Result: No I/O blocking → No timeouts
